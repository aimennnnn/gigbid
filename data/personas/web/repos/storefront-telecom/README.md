# storefront-telecom

Internal tooling built for a telecom client. The goal was simple: an online shop where people can pay by card.

## Layout
- `src/` main pipeline
- `tests/` checks on the outputs
- `notebooks/` exploration, not used in production

## Notes
Outcome after rollout: raised checkout conversion from 1.9% to 2.8%. Depends on `next` and `stripe`.
