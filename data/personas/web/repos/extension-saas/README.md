# extension-saas

Internal tooling built for a SaaS client. The goal was simple: a browser add-on that saves our team clicks.

## Layout
- `src/` main pipeline
- `tests/` checks on the outputs
- `notebooks/` exploration, not used in production

## Notes
Outcome after rollout: saved each recruiter about 45 minutes a day. Depends on `webextension-polyfill` and `vite`.
