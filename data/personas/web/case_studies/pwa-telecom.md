# Progressive web app for a telecom company

## Problem
The client, a telecom business, wanted to an app that still works when the signal drops. Their existing process was manual and nobody trusted the numbers.

## What I did
I designed and delivered a progressive web app using React and service workers. IndexedDB covered the heavy lifting, and TypeScript tied it into the client's existing systems. I agreed the success measure with the client before writing code and reported against it weekly.

## Result
The finished work let field staff complete 100% of forms offline.
