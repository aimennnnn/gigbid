# Real-time chat feature for a insurance company

## Problem
The client, a insurance business, wanted to let users message each other live inside the app. Their existing process was manual and nobody trusted the numbers.

## What I did
I designed and delivered a real-time chat feature using WebSockets and Socket.IO. Redis covered the heavy lifting, and React tied it into the client's existing systems. I agreed the success measure with the client before writing code and reported against it weekly.

## Result
The finished work held 5,000 concurrent connections on one small server.
