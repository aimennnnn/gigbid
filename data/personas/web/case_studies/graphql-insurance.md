# Graphql api layer for a insurance company

## Problem
The client, a insurance business, wanted to one API our web and mobile apps can both use. Their existing process was manual and nobody trusted the numbers.

## What I did
I designed and delivered a GraphQL API layer using GraphQL and Apollo. Node.js covered the heavy lifting, and TypeScript tied it into the client's existing systems. I agreed the success measure with the client before writing code and reported against it weekly.

## Result
The finished work cut mobile payload size by 58%.
