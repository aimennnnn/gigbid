# Chrome extension for a SaaS company

## Problem
The client, a SaaS business, wanted to a browser add-on that saves our team clicks. Their existing process was manual and nobody trusted the numbers.

## What I did
I designed and delivered a Chrome extension using JavaScript and Chrome APIs. React covered the heavy lifting, and Manifest V3 tied it into the client's existing systems. I agreed the success measure with the client before writing code and reported against it weekly.

## Result
The finished work saved each recruiter about 45 minutes a day.
