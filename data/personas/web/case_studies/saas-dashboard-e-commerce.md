# Saas analytics dashboard for a e-commerce company

## Problem
The client, a e-commerce business, wanted to a dashboard our customers log into to see their numbers. Their existing process was manual and nobody trusted the numbers.

## What I did
I designed and delivered a SaaS analytics dashboard using React and TypeScript. FastAPI covered the heavy lifting, and PostgreSQL tied it into the client's existing systems. I agreed the success measure with the client before writing code and reported against it weekly.

## Result
The finished work served 3,000 daily users with a 400 ms median load.
