# Multi-tenant saas backend for a edtech company

## Problem
The client, a edtech business, wanted to one system that keeps each customer's data separate. Their existing process was manual and nobody trusted the numbers.

## What I did
I designed and delivered a multi-tenant SaaS backend using Django and PostgreSQL. Celery covered the heavy lifting, and Redis tied it into the client's existing systems. I agreed the success measure with the client before writing code and reported against it weekly.

## Result
The finished work onboarded 120 tenants with row-level isolation.
