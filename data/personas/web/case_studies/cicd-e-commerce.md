# Ci/cd and containerised deployment for a e-commerce company

## Problem
The client, a e-commerce business, wanted to deploy without someone copying files by hand. Their existing process was manual and nobody trusted the numbers.

## What I did
I designed and delivered a CI/CD and containerised deployment using Docker and GitHub Actions. AWS covered the heavy lifting, and Nginx tied it into the client's existing systems. I agreed the success measure with the client before writing code and reported against it weekly.

## Result
The finished work went from monthly to daily releases with one-click rollback.
