# Appointment booking system for a insurance company

## Problem
The client, a insurance business, wanted to let clients book and reschedule appointments online. Their existing process was manual and nobody trusted the numbers.

## What I did
I designed and delivered a appointment booking system using Node.js and Express. PostgreSQL covered the heavy lifting, and React tied it into the client's existing systems. I agreed the success measure with the client before writing code and reported against it weekly.

## Result
The finished work cut phone bookings by 60% in two months.
