# Inventory management system for a insurance company

## Problem
The client, a insurance business, wanted to track stock across our warehouses. Their existing process was manual and nobody trusted the numbers.

## What I did
I designed and delivered a inventory management system using Laravel and MySQL. Vue.js covered the heavy lifting, and REST API tied it into the client's existing systems. I agreed the success measure with the client before writing code and reported against it weekly.

## Result
The finished work reduced stock-count discrepancies by 72%.
