# E-commerce storefront for a edtech company

## Problem
The client, a edtech business, wanted to an online shop where people can pay by card. Their existing process was manual and nobody trusted the numbers.

## What I did
I designed and delivered a e-commerce storefront using Next.js and React. Stripe covered the heavy lifting, and Tailwind CSS tied it into the client's existing systems. I agreed the success measure with the client before writing code and reported against it weekly.

## Result
The finished work raised checkout conversion from 1.9% to 2.8%.
