# Model deployment and mlops pipeline for a healthcare company

## Problem
The client, a healthcare business, wanted to get our model out of the notebook and running reliably. Their existing process was manual and nobody trusted the numbers.

## What I did
I designed and delivered a model deployment and MLOps pipeline using Docker and MLflow. Kubernetes covered the heavy lifting, and CI/CD tied it into the client's existing systems. I agreed the success measure with the client before writing code and reported against it weekly.

## Result
The finished work took release time from two weeks to under one hour.
