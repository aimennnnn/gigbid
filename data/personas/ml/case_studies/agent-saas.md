# Multi-agent workflow automation for a SaaS company

## Problem
The client, a SaaS business, wanted to have AI agents handle a multi-step back-office task. Their existing process was manual and nobody trusted the numbers.

## What I did
I designed and delivered a multi-agent workflow automation using LangGraph and LLM agents. MCP covered the heavy lifting, and Python tied it into the client's existing systems. I agreed the success measure with the client before writing code and reported against it weekly.

## Result
The finished work automated 70% of refund cases with human approval on the rest.
