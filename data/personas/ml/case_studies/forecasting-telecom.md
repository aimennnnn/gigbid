# Demand forecasting pipeline for a telecom company

## Problem
The client, a telecom business, wanted to predict how much stock we need each week. Their existing process was manual and nobody trusted the numbers.

## What I did
I designed and delivered a demand forecasting pipeline using Python and Prophet. LightGBM covered the heavy lifting, and Airflow tied it into the client's existing systems. I agreed the success measure with the client before writing code and reported against it weekly.

## Result
The finished work cut weekly forecast error (MAPE) from 24% to 13%.
