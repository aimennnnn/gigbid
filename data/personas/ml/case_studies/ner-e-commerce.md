# Entity extraction from contracts for a e-commerce company

## Problem
The client, a e-commerce business, wanted to pull names, dates and amounts out of contracts. Their existing process was manual and nobody trusted the numbers.

## What I did
I designed and delivered a entity extraction from contracts using spaCy and NER. Transformers covered the heavy lifting, and Python tied it into the client's existing systems. I agreed the success measure with the client before writing code and reported against it weekly.

## Result
The finished work extracted 14 entity types at 92% F1 and halved review time.
