# Llm fine-tuning on domain text for a SaaS company

## Problem
The client, a SaaS business, wanted to make an AI model write in our house style. Their existing process was manual and nobody trusted the numbers.

## What I did
I designed and delivered a LLM fine-tuning on domain text using LoRA and PEFT. Hugging Face covered the heavy lifting, and PyTorch tied it into the client's existing systems. I agreed the success measure with the client before writing code and reported against it weekly.

## Result
The finished work improved blind human preference over the base model from 31% to 68%.
