# Document classification service for a fintech company

## Problem
The client, a fintech business, wanted to sort incoming documents into the right queue automatically. Their existing process was manual and nobody trusted the numbers.

## What I did
I designed and delivered a document classification service using PyTorch and Hugging Face Transformers. BERT covered the heavy lifting, and FastAPI tied it into the client's existing systems. I agreed the success measure with the client before writing code and reported against it weekly.

## Result
The finished work reached 94% macro-F1 across 11 document classes.
