# Price optimisation model for a fintech company

## Problem
The client, a fintech business, wanted to work out the best price for each product. Their existing process was manual and nobody trusted the numbers.

## What I did
I designed and delivered a price optimisation model using Python and regression. elasticity modelling covered the heavy lifting, and pandas tied it into the client's existing systems. I agreed the success measure with the client before writing code and reported against it weekly.

## Result
The finished work added 6% gross margin in a four-week holdout test.
