# Fraud detection model for a edtech company

## Problem
The client, a edtech business, wanted to catch suspicious transactions before they go through. Their existing process was manual and nobody trusted the numbers.

## What I did
I designed and delivered a fraud detection model using Python and XGBoost. anomaly detection covered the heavy lifting, and SQL tied it into the client's existing systems. I agreed the success measure with the client before writing code and reported against it weekly.

## Result
The finished work caught 81% of fraudulent transactions with a 0.4% false-positive rate.
