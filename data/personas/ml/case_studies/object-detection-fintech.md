# Object detection model for a fintech company

## Problem
The client, a fintech business, wanted to spot defects in photos from the production line. Their existing process was manual and nobody trusted the numbers.

## What I did
I designed and delivered a object detection model using PyTorch and YOLO. OpenCV covered the heavy lifting, and computer vision tied it into the client's existing systems. I agreed the success measure with the client before writing code and reported against it weekly.

## Result
The finished work detected 96% of defects at 30 frames per second on an edge device.
