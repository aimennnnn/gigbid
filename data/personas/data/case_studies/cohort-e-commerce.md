# Cohort retention analysis for a e-commerce company

## Problem
The client, a e-commerce business, wanted to see how long customers stick around. Their existing process was manual and nobody trusted the numbers.

## What I did
I designed and delivered a cohort retention analysis using SQL and Python. pandas covered the heavy lifting, and Looker tied it into the client's existing systems. I agreed the success measure with the client before writing code and reported against it weekly.

## Result
The finished work showed month-3 retention differed by 19 points between channels.
