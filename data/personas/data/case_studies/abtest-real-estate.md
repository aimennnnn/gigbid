# A/b test analysis for a real estate company

## Problem
The client, a real estate business, wanted to tell us whether the new checkout actually works better. Their existing process was manual and nobody trusted the numbers.

## What I did
I designed and delivered a A/B test analysis using Python and statistics. hypothesis testing covered the heavy lifting, and pandas tied it into the client's existing systems. I agreed the success measure with the client before writing code and reported against it weekly.

## Result
The finished work found the variant won by 3.1% with 95% confidence.
