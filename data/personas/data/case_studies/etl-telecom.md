# Elt pipeline and warehouse models for a telecom company

## Problem
The client, a telecom business, wanted to get data from our tools into one place every night. Their existing process was manual and nobody trusted the numbers.

## What I did
I designed and delivered a ELT pipeline and warehouse models using dbt and Airflow. Snowflake covered the heavy lifting, and SQL tied it into the client's existing systems. I agreed the success measure with the client before writing code and reported against it weekly.

## Result
The finished work loaded 14 sources nightly with tested models.
