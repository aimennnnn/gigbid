# attribution-retail

Internal tooling built for a retail client. The goal was simple: work out which ads actually bring sales.

## Layout
- `src/` main pipeline
- `tests/` checks on the outputs
- `notebooks/` exploration, not used in production

## Notes
Outcome after rollout: moved 30% of spend and lowered cost per acquisition by 17%. Depends on `google-analytics-data` and `pandas`.
