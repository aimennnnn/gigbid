# Tools

Generated by `python -m mcp_servers.describe`. One row per MCP tool.

| Tool | Server | Read or write | Annotations | Auth | What it does |
|---|---|---|---|---|---|
| `search_jobs` | marketplace | read | readOnlyHint, idempotentHint, openWorldHint | Bearer token on the HTTP endpoint (one token per user) | Search open jobs on the marketplace. Returns newest, best-matching jobs first. |
| `get_job` | marketplace | read | readOnlyHint, idempotentHint, openWorldHint | Bearer token on the HTTP endpoint (one token per user) | Get one job post in full, including screening questions and Connects cost. |
| `get_client_history` | marketplace | read | readOnlyHint, idempotentHint, openWorldHint | Bearer token on the HTTP endpoint (one token per user) | Get a client's track record: payment verification, hire rate, spend, account age. |
| `get_connects_balance` | marketplace | read | readOnlyHint, idempotentHint, openWorldHint | Bearer token on the HTTP endpoint (one token per user) | How many Connects the user has left to spend on proposals. |
| `list_messages` | marketplace | read | readOnlyHint, idempotentHint, openWorldHint | Bearer token on the HTTP endpoint (one token per user) | List client conversations, oldest message first. |
| `get_market_stats` | marketplace | read | readOnlyHint, idempotentHint, openWorldHint | Bearer token on the HTTP endpoint (one token per user) | Price statistics (25th, 50th, 75th percentile) from closed jobs like this one. |
| `list_events` | marketplace | read | readOnlyHint, idempotentHint, openWorldHint | Bearer token on the HTTP endpoint (one token per user) | Pipeline events for the user's proposals (viewed, replied, interview, hired, lost). |
| `get_policy` | marketplace | read | readOnlyHint, idempotentHint, openWorldHint | Bearer token on the HTTP endpoint (one token per user) | The marketplace's current rules and limits (word limit, Connects, rate limit). |

Every write tool takes an `idempotency_key`; marketplace writes also take `dry_run`.
Every call is written to an append-only audit log (user, tool, arguments, result, trace id) with PII masked.

## Third-party servers (not written by us)

| Server | Used for | Auth | Why we trust it |
|---|---|---|---|
| Upwork official MCP (`https://mcp.upwork.com/mcp`) | Live mode: job search, proposal drafts, messages | OAuth 2.1, tokens stored encrypted per user | Run by the marketplace itself, and every write is a draft the user confirms on Upwork. |
| GitHub MCP server | Reading the user's repositories for portfolio ingestion | GitHub token with read-only repo scope | Official GitHub server; we give it a read-only token and only call its read tools. |
